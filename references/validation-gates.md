# 验收门禁

## 内容

- 生图前已生成并锁定 `compositionPlan`；其中内容职责、语义单元、页数区间、版式配方、图片职责和禁止项齐全。
- S/P/K/M/L 每章都有四字段封面导演卡；缺少 `coreObject`、`emotionVerb`、`smallContrast` 或合法 `grammar` 时不得进入生图。
- S 节拍成立，无主角时不强塞人物。
- P 原图 SHA-256、像素尺寸和比例一致。
- P 有独立语义封面；封面与正文原图不是同一资源，导演卡四项齐全，人工确认不是滤镜化、转绘或复刻构图。
- K 事实、编辑标题、视觉旁注可区分，来源可追溯。
- K 方法/流程的背景、完整步骤组和用户反应没有被标点机械拆散。
- M 发言人、决定、风险、未决、待办、负责人、期限与状态完整。
- L 原文字句、标点、段落和顺序一致。
- 复合输入的来源单元都能映射到章节。

## 视觉

至少检查：

- 1080×1440
- 135×180
- 1440px 桌面
- 390px 手机
- 文字溢出
- 图片缺失
- 安全区
- 局部碰撞
- 插图与正文相交
- 横向滚动
- 控制台错误
- 页面过空或过挤
- 阅读顺序
- 页面底色为 `#FFFFFF`，白色面积与纸纹符合设计基线
- 正文没有使用手写字体，字体角色不超过三种
- 模板、材料和主视觉位置遵守冷却规则
- 当前结果引用 `ache-design-system/1.10.0`，不是临时重建版式
- 封面与月封均为独立 3:4 资产；不得从正文图、照片或连续场景中裁一块充当封面
- 资产来源通过 `asset-contract`：禁止 `fraction-crop`；sheet crop 必须声明 `isolated-cells`、安全间隔和精确单元格边界
- 图片内容框和图片比例误差不超过 2.5%，外框留边不超过短边 7%；重复固定矩形框、框大图小和多层套框均阻塞
- 不规则窗口只裁安全背景边缘；原照片不使用遮罩裁切，关键主体可见像素完整
- K/M/L 页边组件为透明 PNG/WebP 或 SVG，不存在白色矩形底和假透明底；透明性由实际文件检查确认，不接受只写 `backgroundMode` 的自报状态
- 每章存在 `data-theme-source`，色板跟随画风与主题；白底固定但点睛色不得被 02 冰蓝全局绑死
- 知识、会议和长文的解释插图以完整独立组件整图使用；`explanatory-vignette` 与 `decorative-component` 禁止任何 sheet crop
- 页面分为四个水平密度带检查；有效构图低于 75%、底部出现无意义空带或局部拥挤时不得通过
- 文字主导页的实际有效占页率位于 62%–88%；最后一个有意义元素之后的空带不超过页内容区 25%。不可用透明元素、无意义线条或放大装饰伪造占页率。
- 长文相邻正文段落的最大连续空白不超过正文内容区 12%；禁止页面虽然触底、内部却出现巨大空洞。
- 纠偏按 `轻移位 → 局部压缩 → 标题/段落节奏调整 → 换配方或分页`，不得先缩正文
- HTML 由 `scripts/page-renderer.mjs` 生成，存在清晰的 3:4 `.ache-page` 页面边界
- 没有通栏博客、全宽大图连续堆叠、裸会议段落或平台临时 UI 卡片
- 标题、正文、主视觉与页脚的矩形两两不相交
- 所有 `.ache-page` 的 `scrollHeight/clientHeight` 与 `scrollWidth/clientWidth` 无隐藏溢出
- 所有未显式允许裁切的图片均为 `object-fit: contain`，原图可见比例为 100%
- 390px 手机正文计算字号不低于 12px
- 预排版 3:4 成品页直接占满页面，不存在第二层纸托、缩略框或标题覆盖
- 创刊画风选择图取得 `displayed: true` 展示回执；内部工具 JSON 不得出现在用户界面

技术 `PASS` 后仍要看原尺寸和手机缩略。

再与已验收 good case 做审美回归，不要求版式相同，但必须保住：白底和克制材料层、标题与主视觉的关系、每页一个真正的视觉趣味点、正文类型辨识度。若新版只是更规整，却退化成博客、PPT、图片堆叠或通用模板，仍判失败。

逐类型复核：

- S：封面与正文不是同一复合图的重复裁片；多格主体完整、镜头有推进。
- P：语义封面独立，正文原图完整；照片周围的手帐关系比默认图片框更有设计感。
- K：正文脱离图片仍可读；解释图落在真正需要呼吸或理解的位置，不按知识点堆图。
- M：主题、过程、决定、风险和行动有编辑层次；普通会议不做多格漫画，也不退化为裸项目符号；不得用多开稀薄页来回避一页的编辑编排。
- L：原文字体和段落节奏适合长读；轻插图作为单列正文流中的段间节点呼吸，不占 K/M 式侧栏，不把正文切成卡片；段落自然连续，不使用 `space-between` 强行铺满。

## 月册

- 每个月册有独立月封；月封位于第一章之前，不拿章节封面替代
- 同月只有一个用户主入口。
- 跨月创建新月册并更新系列书架。
- 旧事回填只改对应月份。
- 幂等重试不重复章节。
- 并发无重复序号或文件损坏。
- 待补图仍可阅读和继续追加。

## 载体

- 本地：断网可读，链接与图片有效。
- 飞书：仅使用已核验的个人账号；回读 block、图片、warnings/degrade 和 revision。
- 飞书月册使用 `feishu-image-edition/1.0.0` 连续画册：只有月册标题、一句导语和按页码排列的成品页。
- 飞书写入前必须拦截缺页、重复页、乱序、非1080×1440、低清页、超过20MB、缺少上传token或源HTML桌面/手机QA失败。
- 飞书写入后回读的图片数量、`name`页序、warnings/degrade和revision必须全部吻合；平台转码允许，裁切、丢页和乱序不允许。
- GitHub：公开包已脱敏；未授权不 push。

## 便携分享

- 单章只含目标章节；单册、单部、单本包含的月份和顺序准确。
- 复制成品 HTML 到没有 `assets/` 的空目录，关闭网络后仍能完整阅读。
- 所有必需图片 `naturalWidth > 0`，无缺图标记、控制台错误或远程资源请求。
- 轻量版不依赖本地字体文件；保真版内嵌字体且 `document.fonts` 可加载。
- HTML 不含 `file://`、本机绝对路径、未内嵌 `src` 或 CSS `url(...)`。
- 1440px 桌面和 390px 手机均无横向滚动、遮挡和异常缩放。
- 用户选择前只报告估算大小；选择后报告真实文件大小和输出位置。
- 便携副本不得改写默认 `HTML + assets` 主版本。

## 阻塞

以下任一项阻止正式提交或安装：

- 内容失真
- 飞书账号错误或身份未知
- 私密内容进入公开包
- 无生图时直接拒绝
- 同月产生多个用户主文件
- 候选画风被冒充已验证
- 视觉错误
- 并发或恢复错误
- 未经授权的外部写入
- 便携分享版离开 `assets` 后缺图或依赖网络
