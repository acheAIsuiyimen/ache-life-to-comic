# 验收门禁

## 内容

- S 节拍成立，无主角时不强塞人物。
- P 原图 SHA-256、像素尺寸和比例一致。
- K 事实、编辑标题、视觉旁注可区分，来源可追溯。
- M 发言人、决定、风险、未决、待办、负责人、期限与状态完整。
- L 原文字句、标点、段落和顺序一致。
- 复合输入的来源单元都能映射到章节。

## 视觉

至少检查：

- 1080×1440
- 135×180
- 1440px 桌面
- 390px 手机
- 文字溢出
- 图片缺失
- 安全区
- 局部碰撞
- 插图与正文相交
- 横向滚动
- 控制台错误
- 页面过空或过挤
- 阅读顺序
- 页面底色为 `#FFFFFF`，白色面积与纸纹符合设计基线
- 正文没有使用手写字体，字体角色不超过三种
- 模板、材料和主视觉位置遵守冷却规则
- 当前结果引用 `ache-design-system/1.1.0`，不是临时重建版式
- HTML 由 `scripts/page-renderer.mjs` 生成，存在清晰的 3:4 `.ache-page` 页面边界
- 没有通栏博客、全宽大图连续堆叠、裸会议段落或平台临时 UI 卡片
- 创刊画风选择图取得 `displayed: true` 展示回执；内部工具 JSON 不得出现在用户界面

技术 `PASS` 后仍要看原尺寸和手机缩略。

## 月册

- 同月只有一个用户主入口。
- 跨月创建新月册并更新系列书架。
- 旧事回填只改对应月份。
- 幂等重试不重复章节。
- 并发无重复序号或文件损坏。
- 待补图仍可阅读和继续追加。

## 载体

- 本地：断网可读，链接与图片有效。
- 飞书：仅使用已核验的个人账号；回读 block、图片、warnings/degrade 和 revision。
- GitHub：公开包已脱敏；未授权不 push。

## 便携分享

- 单章只含目标章节；单册、单部、单本包含的月份和顺序准确。
- 复制成品 HTML 到没有 `assets/` 的空目录，关闭网络后仍能完整阅读。
- 所有必需图片 `naturalWidth > 0`，无缺图标记、控制台错误或远程资源请求。
- 轻量版不依赖本地字体文件；保真版内嵌字体且 `document.fonts` 可加载。
- HTML 不含 `file://`、本机绝对路径、未内嵌 `src` 或 CSS `url(...)`。
- 1440px 桌面和 390px 手机均无横向滚动、遮挡和异常缩放。
- 用户选择前只报告估算大小；选择后报告真实文件大小和输出位置。
- 便携副本不得改写默认 `HTML + assets` 主版本。

## Skill

- frontmatter 只有 `name` 和 `description`
- 名称与目录一致
- `agents/openai.yaml` 与 SKILL.md 一致
- SKILL.md 少于 500 行
- references 一层可达
- 无 README、凭证、用户数据和平台专属图片模型参数
- `quick_validate.py` 通过

## 阻塞

以下任一项阻止正式提交或安装：

- 内容失真
- 飞书账号错误或身份未知
- 私密内容进入公开包
- 无生图时直接拒绝
- 同月产生多个用户主文件
- 候选画风被冒充已验证
- 视觉错误
- 并发或恢复错误
- 未经授权的外部写入
- 便携分享版离开 `assets` 后缺图或依赖网络
