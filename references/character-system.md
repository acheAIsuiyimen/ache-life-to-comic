# 角色系统

角色可选，不是连载成立的前提。

## 四级介入

0. 无角色：物件、天气、空间和动作完成叙事。
1. 匿名临时人物：只服务当前章节，不写入持续角色库。
2. 页边穿插角色：批注、观察或轻动作，不抢正文。
3. 进入场景角色：参与真实动作，但不代替用户、作者或参会者表达。

同一页只使用一个介入级别。先判断无角色是否成立，再提高介入。

## 持续角色卡

至少保存：

- 稳定 ID
- 类型
- 外观锚点
- 性格与语气
- 常用动作
- 禁止动作
- 与用户关系
- 允许介入的内容
- 默认频率
- 参考图

## 自定义 IP

对普通用户，持续角色的核心入口是自己的 IP：人物、宠物、品牌角色或有辨识度的物件。第一次只收集 1–5 张参考图和四个稳定锚点，后续按页边穿插或进入场景的方式低成本续用。

角色不必成为主角，也不必每章出现。它的价值是让“这是我的书”越来越明显。

## 66 大王

66 大王是 Skill 内置的持续角色示例；不自动写入用户的书。使用 `assets/characters/66-dawang/` 中的锚点：

- 灰色长毛猫
- 黑色贝雷帽
- 圆框眼镜
- 黄绿色眼睛
- 千鸟格领巾
- 手绘铅笔与粉蜡质感

出现时要有动作或叙事职责，不做角落贴纸。不能替代真实人物发言，不能抢走用户故事的中心。

## 一致性

不要承诺绝对锁脸。根据平台能力选择：

- 严格：背影、局部、标志物、固定角度
- 标准：多角度但保留四锚点
- 自由：允许较大解释变化

技术漂移必须标记并修复，不得自动解释成梦境或新角色。
