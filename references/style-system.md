# 画风系统

## 生命周期

- `validated_preset`：完成全路线、四视图和用户验收，可作为默认。
- `optional_candidate`：可以被用户主动选择，但首次使用必须轻校准。
- `book_calibrated_candidate`：候选已为当前书通过轻校准。
- `custom_candidate`：用户参考图已解析，尚未校准。
- `custom_validated`：用户为当前书确认自定义校准。
- `archived`：不进入选择器。

## 参考图

接收 1–5 张。提取画风 DNA：

- 媒介
- 笔触
- 轮廓
- 色板
- 对比度
- 人物比例
- 空间与镜头
- 留白
- 纸张材料
- 漫画运动线
- 禁止项

不要提取具体角色、品牌、题材、地点和原图构图。

## 轻校准

候选或自定义风格首次使用时：

1. 选用户当次的一小段内容。
2. 生成一张章节封面。
3. 生成一张标准内容页。
4. 检查原尺寸、缩略图、人物/无人物、准确文字和版式。
5. 让用户用选择题确认：通过、轻微调整、换方向。
6. 只更新当前书画风卡。

## 跨平台

画风卡使用语义属性，不存平台专属提示参数。平台适配层可以翻译媒介、笔触与约束，但不得改变：

- 生命周期
- 白底与成熟度
- 核心色板
- 人物锚点
- 禁止儿童化
- 准确文字后排

跨平台回归比较风格锚点和视觉门槛，不比较像素哈希。

## 02 轻插画下限

无生图时不能借“降级”逃离 02：

- 白色占主面积，冰蓝承担结构与空气，炭灰承担正文，珊瑚红最多是一处小强调；
- 线条允许不均匀，色块带粉蜡或干刷颗粒；页面仍像漫画手帐，不像产品说明卡；
- 不使用黄色聚光灯、橙色流程点、厚重圆角白卡、悬浮阴影或标准组件网格，除非用户参考图明确要求；
- K/M/L 的少图是“正文主导 + 一处真正需要的解释图”，不是把段落装进多个卡片；
- 技术 QA 后再做一次画风 QA：主色、笔触、材料、版式和禁用语言任一漂移即退回修正。
