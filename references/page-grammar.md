# 页面语法

## 共同底盘

- 3:4 竖版
- 固定 `#FFFFFF` 大背景，白色占 70%–85%
- 纸纹透明度 2%–6%，不得染成米黄、奶油黄或牛皮纸底
- 手帐材料层
- 明确漫画阅读顺序
- 准确文字后期排版
- 页面密度服从内容
- 线上自然纵向滚动

所有比例、字体角色、模板冷却和禁用项以
`assets/layout-system/design-baseline.json` 为准。先调用 `layout-plan.mjs`，再生成画面或排文字。

生成前还必须产生 `compositionPlan`，一次锁定：内容职责、语义单元、页数区间、版式配方、图片职责、目标占页率和禁止项。没有这份预排合同，不得进入生图或平台排版。

## 自适应硬规则

- 先计算标题、正文、图片和页脚的真实区域，再选择单页或拆页；不得先锁坐标再把内容塞入。
- 标题允许自然平衡换行，禁止 `white-space: nowrap`；不出现单字尾行或标题压图。
- 主图片区、正文区和页脚处于正常网格流中，三者矩形不得相交。
- 图片默认完整显示；外层手撕纸、邮票齿和异形轮廓不能裁掉图片可见像素。
- 生成图先按最终放置槽的实际比例生成；框内容区必须跟图同宽高比。框可以存在，但不得出现大框、小图、粗留边和多层矩形嵌套的硬贴感。
- 不规则裁切只用于已声明安全主体区的生成插画；原照片使用不规则纸托而不是遮罩裁图。页边小插画优先透明底或 SVG。
- 一张已经排好文字和页码的 3:4 成品页只可整页展示，不得再套进封面窗或正文图框。
- 页面超出容量时沿语义边界拆页；手机正文不得低于 12px，不能以缩字替代分页。
- 先按图片实际宽高分类为竖、近竖、方、横或超横，再选择版式配方；不得只按图片数量套模板。
- 浏览器实测按四个水平密度带检查；溢出按 `1–40px 轻移位 / 41–90px 局部压缩 / 91–160px 节奏调整 / 161px+ 换配方或分页` 处理。

## S 日常

提取 1–8 个节拍，常见结构：

- 发生
- 感觉
- 留下

先把内容标准化为最多 8 个有顺序的 `beats`，再调用 `plan-entry.mjs`。脚本输出 `panelPlan`，固定每页格数、原始节拍索引与自上而下阅读顺序：

| 节拍数 | 正文页格数 |
|---:|---|
| 0–1 | `1` |
| 2 | `2` |
| 3 | `3` |
| 4 | `2 + 2` |
| 5 | `2 + 3` |
| 6 | `3 + 3` |
| 7 | `2 + 2 + 3` |
| 8 | `2 + 3 + 3` |

`3` 格不等于 `3` 次生图。可以一次生成带宽安全间隔的独立单元格素材表，也可以生成独立资产；必须在 `asset-contract` 中保存单元格边界、来源组和安全间隔。禁止从一幅连续场景任意切三块。加上封面，通常仍为两次基础视觉调用。

页面使用上→下的不等高编辑式布局，不使用三角堆叠。必须保持同一事件连续、节拍原序和镜头或状态变化；禁止三张互不相关的插画。

纯文字尚未拆出节拍时，只生成一格 `single-moment-from-text`，不凭空扩写成三格。文字很长时先判断应拆出真实节拍，还是转为 L 长文；不能仅因字数制造空页。

无角色时使用：

- 手和局部动作
- 物件状态变化
- 空间和天气
- 光线与影子
- 视线方向
- 声音、气味、温度的视觉隐喻

## P 照片

- 原图只读
- 不裁切、不重绘、不发送给生成模型
- 横、竖、方图完整自适应
- 手撕纸和异形效果在照片外层实现
- 多图默认上到下，不用三角堆叠
- 小插画只能从照片可见证据生长
- 章节仍有独立封面
- 封面必须从照片可见物件、天气、时间感和用户文字中提炼独立语义创意；不得引用正文原图文件，不得沿用原机位把照片换媒介重画。正文负责 100% 完整照片证据。
- 三张正文图可在纵向接力、错落手帐、主格加两小格中选择；仍按从上到下阅读，不得排成三角，也不得把人物或物件裁残。
- 具体选择由原图比例组合决定，不固定为同一三图骨架。

## K 知识

先写出脱离图片也能读懂的正文，再判断是否需要解释图。

只为以下关系配图：

- 过程
- 因果
- 尺度
- 状态变化
- 对比
- 空间关系

默认每 1–3 页一个视觉呼吸点。禁止一个知识点一张大图。
默认使用 C 手写档案页：正文是主体，图片只解释过程、关系、尺度或状态变化。

方法/流程型知识先分为：

1. 来源或背景；
2. 完整的因果、过程或步骤组；
3. 边界或注意；
4. 用户自己的理解/反应。

分号、冒号和换行只是语法线索，不是分页或分段命令。同一方法的步骤必须编辑成一个连续阅读组；不得出现“提词器；”这类失去上下文的独立段落。
解释插图必须以完整、独立组件生成并整图使用；不得从共享大图、素材表或连续画面裁出局部充当页边插图。

文案标记：

- `fact`：来源事实
- `editorial_title`：编辑标题
- `visual_note`：视觉阅读提示
- `user_reflection`：用户理解或反应

## M 会议

默认正文主导、轻配图。按会议实际密度选择：

1. 封面
2. 发言进程
3. 决定、风险与未决
4. 行动卡

短会议可以压缩。必须完整保留：

- 主题与时间
- 发言人
- 决定
- 风险
- 未决
- 待办
- 负责人
- 期限
- 状态

66 大王等角色不能代替真实参会者发言。
默认使用 C 手写档案页，不因为会议字段多就增加同等数量的插图。

会议正文必须结构化解析后分级排版，禁止 flatten 成全是无重点的无序列表：

- 元信息（主题/时间/地点/参会人）排成浅底信息条
- 章节（一/二/三…）有手绘感小标题；章节语气继承——决议章节全部条目用决议标记、待办章节全部用勾选框，同一张列表不混用标记
- 条目按语气分级：决议=编号圆圈+加粗；待办=勾选框；明示风险（"风险点：…"等）=珊瑚色波浪下划线；讨论常规措辞不作风险标记；P0/P1/P2 渲染为珊瑚色优先级标签
- "下次会议"排成独立条带
- 分页按语义块（元信息/章节/下次会议）而非字符硬切：章节标题永远和它的第一条目同页（不孤儿），尾页过轻时从上一页尾部均衡搬迁，保持阅读顺序

会议页文字优先、轻配图：重要内容永远排版成上面的结构化文字，绝不把决议、排期表、待办清单当图片摆出来。会议图片资产最多挑一张，以可读尺寸作为"现场记录"照片贴纸贴在留白最多的页面；没有合适位置就不贴，其余图片不上页。

生成前必须给每一页分配一个主要职责：背景/议题、讨论/证据、决议/风险、行动/下次会议。相邻职责可合页，但不允许同一责任被分散到多个稀薄页。普通会议为 0–1 个独立页边插图，默认不生成多格漫画。
会议轻插图同样必须是完整独立组件；不得把会议要素画成一张大图后再裁出镇纸、纸页或人物局部。

## L 长文

- 原文逐字、逐段、同序
- 不摘要、不润色、不对白化
- 默认不新增小标题
- 先把完整正文试排一页
- 真实占用率低于约 45% 时优先合并
- 高于约 82% 时才沿自然语义边界拆分
- 不产生只有一两个短段落的孤立尾页
- 长段先拆成较小语义单元再装页，避免一个大段把短开头孤立成空页；字符和顺序不得改变
- 每 1–3 页最多一个轻插图组
- 默认使用 C 手写档案页；插图作为单列正文流中的独立节点在段落之间呼吸，不能占侧栏、不能触发双栏，也不能把正文拆成 UI 卡片
- 每页目标有效占页率 62%–88%，底部无功能空带不超过 25%
- 段落按自然文流连续向下排列，禁止为了触底使用 `space-between`、固定高度分区或透明元素拉开段落
- 短引语可以成为轻量 pull quote，但仍留在上下文附近；相邻段落之间的最大连续空白不超过正文内容区 12%
- 页数依照实排容量与自然语义边界决定，不依照原段数、标点数或图片数倒推

## 无图 K/M/L 页 · 留白区贴纸（whitespace-zone sticker placement）

无生成配图（或配图仅作点缀）的 K/M/L 正文页用贴纸补足手帐感。铁律如下：

- **正文优先，一字不截**：正文始终 100% 宽度、完整、自然排版；禁止为放元素截断文字、拆分段落/列表、压缩栏宽或让文字绕排（float 强制留位等于在纸上硬挖一个洞，违背手帐逻辑）
- **留白区是真实排版空间**：贴纸只住在正文排完之后自然产生的「留白区」（sticker zone）里——它是纵向 flex 流中正文之后的真实空间（`flex:1`），而不是绝对定位的悬浮层，因此贴纸原理上不可能遮字、不可能飞出页面、不可能压住页眉页脚
- **贴着文字末尾**：贴纸锚定在留白区上部（紧挨正文结束的位置），像写完字随手在旁边一贴；禁止在大片留白里垂直居中（漂在荒原中央、脚下留死白）；左右位置由 `episodeId|pageIndex` 种子决定，重渲稳定，同册相邻页不重复同一侧
- **密度自适应**：字号档位（short/regular/dense）按预估渲染高度选择——优先大字号撑满页面，装不下才降档；贴纸尺寸随剩余留白档位（roomy/regular/tight）缩放，字少贴大、字多贴小；留白不足约 100px 时宁可不贴，保留干净的页脚呼吸
- **贴纸形态**：有配图素材且留白足够时用「胶带拍立得」照片贴纸（白边相纸 + 和纸胶带 + 微旋转 + 柔和投影，可带手写小图注如会议页"现场记录"）；无素材时用透明底 SVG 贴纸（`svg-vector` + `verified-transparent`，和纸胶带固定），语义场景按路由分：K=档案、M=行动、L=阅读
- 数据契约 `data-supporting-visual-placement="whitespace-zone"`；贴纸必须出现在 `.ache-sticker-zone` 内，否则视为回归

## 字体

- 标题使用编辑感中文标题字，可加一处手绘笔触。
- 正文统一稳定的中文宋体或黑体，长文和事实禁止手写字体。
- 手写字只用于短边注、情绪与动作，单条不超过 22 个汉字。
- 一页最多三种文字角色、两种手绘笔触。
- 中文、日期、页码、来源全部后期确定性排版；生图画面内禁字。

## 密度

阻塞问题：

- 文字、图片或页码相交
- 阅读顺序不清
- 下方无功能留白过大
- 图片全挤在上半区
- 中间横图过大
- 手帐材料变成装饰堆叠
- 页面像 PPT、UI 卡片或儿童作业
- 固定矩形框反复出现，或框图比例不匹配
- 小插画带白色矩形底，像素材截图而不是落在纸上的元素
- 所有章节无视画风和主题沿用同一套点睛色
