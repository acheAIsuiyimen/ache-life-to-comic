# 页面语法

## 共同底盘

- 3:4 竖版
- 固定 `#FFFFFF` 大背景，白色占 70%–85%
- 纸纹透明度 2%–6%，不得染成米黄、奶油黄或牛皮纸底
- 手帐材料层
- 明确漫画阅读顺序
- 准确文字后期排版
- 页面密度服从内容
- 线上自然纵向滚动

所有比例、字体角色、模板冷却和禁用项以
`assets/layout-system/design-baseline.json` 为准。先调用 `layout-plan.mjs`，再生成画面或排文字。

## S 日常

提取 1–8 个节拍，常见结构：

- 发生
- 感觉
- 留下

先把内容标准化为最多 8 个有顺序的 `beats`，再调用 `plan-entry.mjs`。脚本输出 `panelPlan`，固定每页格数、原始节拍索引与自上而下阅读顺序：

| 节拍数 | 正文页格数 |
|---:|---|
| 0–1 | `1` |
| 2 | `2` |
| 3 | `3` |
| 4 | `2 + 2` |
| 5 | `2 + 3` |
| 6 | `3 + 3` |
| 7 | `2 + 2 + 3` |
| 8 | `2 + 3 + 3` |

`3` 格不等于 `3` 次生图。默认每个正文页生成一个复合漫画画面，因此单页三格仍只占一个正文视觉调用；加上封面，通常为两次视觉调用。

页面使用上→下的不等高编辑式布局，不使用三角堆叠。必须保持同一事件连续、节拍原序和镜头或状态变化；禁止三张互不相关的插画。

纯文字尚未拆出节拍时，只生成一格 `single-moment-from-text`，不凭空扩写成三格。文字很长时先判断应拆出真实节拍，还是转为 L 长文；不能仅因字数制造空页。

无角色时使用：

- 手和局部动作
- 物件状态变化
- 空间和天气
- 光线与影子
- 视线方向
- 声音、气味、温度的视觉隐喻

## P 照片

- 原图只读
- 不裁切、不重绘、不发送给生成模型
- 横、竖、方图完整自适应
- 手撕纸和异形效果在照片外层实现
- 多图默认上到下，不用三角堆叠
- 小插画只能从照片可见证据生长
- 章节仍有独立封面

## K 知识

先写出脱离图片也能读懂的正文，再判断是否需要解释图。

只为以下关系配图：

- 过程
- 因果
- 尺度
- 状态变化
- 对比
- 空间关系

默认每 1–3 页一个视觉呼吸点。禁止一个知识点一张大图。
默认使用 C 手写档案页：正文是主体，图片只解释过程、关系、尺度或状态变化。

文案标记：

- `fact`：来源事实
- `editorial_title`：编辑标题
- `visual_note`：视觉阅读提示
- `user_reflection`：用户理解或反应

## M 会议

默认正文主导、轻配图。按会议实际密度选择：

1. 封面
2. 发言进程
3. 决定、风险与未决
4. 行动卡

短会议可以压缩。必须完整保留：

- 主题与时间
- 发言人
- 决定
- 风险
- 未决
- 待办
- 负责人
- 期限
- 状态

66 大王等角色不能代替真实参会者发言。
默认使用 C 手写档案页，不因为会议字段多就增加同等数量的插图。

## L 长文

- 原文逐字、逐段、同序
- 不摘要、不润色、不对白化
- 默认不新增小标题
- 先把完整正文试排一页
- 真实占用率低于约 45% 时优先合并
- 高于约 82% 时才沿自然语义边界拆分
- 不产生只有一两个短段落的孤立尾页
- 每 1–3 页最多一个轻插图组
- 默认使用 C 手写档案页；插图在段落之间呼吸，不能把正文拆成 UI 卡片

## 字体

- 标题使用编辑感中文标题字，可加一处手绘笔触。
- 正文统一稳定的中文宋体或黑体，长文和事实禁止手写字体。
- 手写字只用于短边注、情绪与动作，单条不超过 22 个汉字。
- 一页最多三种文字角色、两种手绘笔触。
- 中文、日期、页码、来源全部后期确定性排版；生图画面内禁字。

## 密度

阻塞问题：

- 文字、图片或页码相交
- 阅读顺序不清
- 下方无功能留白过大
- 图片全挤在上半区
- 中间横图过大
- 手帐材料变成装饰堆叠
- 页面像 PPT、UI 卡片或儿童作业
