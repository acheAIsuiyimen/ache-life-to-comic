# 固定设计系统

这是所有画风、页面和平台共享的基础层。每次规划与验收都读取
`assets/layout-system/design-baseline.json`；不得凭当次灵感重建白底、字体、留白或模板规则。

## 唯一基线

- 版本：`ache-design-system/1.5.0`
- 来源：已验收的漫画人生设计排版手册与 02 雪色粉蜡试刊
- 原则：先复用已确认模板，再做有版本的扩展
- 平台或模型只能翻译实现方式，不能改变比例、文字角色和禁用项
- 实际输出必须调用 `scripts/page-renderer.mjs` 和
  `assets/templates/page-system.css`；模板 ID 不是让平台自由重写 HTML 的建议
- 标题区、正文区、图片区和页脚必须使用正常文档流或网格布局；文字不得靠绝对坐标压在图片旁边。
- 图片默认 `contain` 并完整可见。只有资产显式声明 `allowCrop: true` 时才允许 `cover`；原始照片永不允许声明裁切。
- 资产必须先经过 `scripts/asset-contract.mjs`：封面和月封是独立 3:4 资产；连续场景不得按比例任意切片；宫格只允许带安全间隔的独立单元格。
- 长页面采用“版式配方 → 四段密度检查 → 分级纠偏”。溢出 160px 以上直接换配方或分页，不得先缩正文。
- 页面有效构图原则上不少于 75%；底部出现无法解释的整段空区即视为版式失败。
- 长文保持自然段落流，禁止用 `space-between` 把段落强制铺满；相邻正文段落之间的最大连续空白不得超过正文内容区 12%。
- 内容超出页面容量时增加页面，不得通过缩小到低于手机 12px、压缩行距或隐藏溢出来换取技术 PASS。

## 图与框

- 框是可选材料，不是每张图的默认容器。无框、轻纸托、手撕纸外沿、不规则窗口和透明贴纸按页面职责选择，一页避免重复套同一种框。
- 生成前先确定最终放置区像素尺寸，按该比例生图；框的内容区比例与图片比例误差不超过 2.5%，外框留边不超过短边 7%。禁止先画固定长方形框，再用 `contain` 把不同比例图片缩进去。
- 原始照片完整保留；手撕效果作用在照片外侧纸托，不裁照片。生成插画可使用不规则窗口，但必须声明安全主体区，裁切只能发生在安全背景边缘。
- K/M/L 的解释小插画默认透明位图或 SVG，直接融入白纸；不得带白色矩形底、相框、素材卡或伪透明底。

## 主题色板

- 页面大背景始终为 `#FFFFFF`，但点睛色不固定为冰蓝。
- 色板优先级为：用户指定 → 参考图 → 原照片确定性取色 → 本章主题/情绪 → 画风默认色板。
- 每章保存 `ink/soft/primary/pale/accent/paper` 六个 token；`paper` 永远为白色，其他 token 可随画风和主题变化。像素夜景可以使用紫蓝与洋红，03 白纸彩铅可以偏草绿，04 双色线记可以偏蓝红。
- 主题变化只作用于标题线、边注、细框、胶带、页码与小面积装饰，不把整页染色，也不超过两组内容色。

## 白底

- 页面底色固定 `#FFFFFF`，白色占 70%–85%。
- 纸纹只能是 2%–6% 的透明质感，不能把白纸染成米黄。
- 米黄、牛皮纸、羊皮纸和暖黄色整页底默认禁用。
- 只有票据、旧信、咖啡纸袋等内容证据确实需要时，才允许小面积语义材料。
- 图片提示和后期排版都要分别执行这条规则，不能只靠其中一层。

## 字体角色

一页最多三种文字角色，不按“好看”临时换字体：

1. 标题：编辑感中文标题，可加少量手绘动作，通常不超过 14 个汉字。
2. 正文：稳定可读的中文宋体或黑体，禁止长正文使用手写字体。
3. 边注：只承载情绪、动作和私人痕迹，单条不超过 22 个汉字。

中文、日期、页码、来源和结构字段全部由确定性排版生成。生图画面不得生成文字。

## 固定模板库

- A 白纸物件剧场：无照片的日常与单一情绪。
- B 照片异形窗口：完整保留照片，用手撕纸或异形纸托组织。
- C 手写档案页：知识、会议、读书笔记和长文，正文主导，少量解释图。
- D 单物图腾：章节封面和结尾。
- E 连续动作漫画：至少两个真实节拍发生状态变化时使用。

模板不是静态版式。通过主视觉位置、比例、纸托形状和边注方向做变化；同一骨架不能连续使用三页。

## 图片与留白

- 主视觉占 28%–58%，留白占 40%–65%。
- 一页最多两组材料，且只能保留一个主要视觉惊喜。
- 三张照片默认自上而下接力；禁止三角堆叠。
- 多格漫画不使用等宽栏目，主格占 45%–60%。
- K/M/L 默认每 1–3 页最多一个解释或边角插图组。

## 变更纪律

任何新样式都必须：

1. 继承这份基线；
2. 新增版本号与变更原因；
3. 通过原图、缩略图、桌面和手机四视图；
4. 不覆盖已验收版本。

当参考图与基线冲突时，先保留用户明确指定的内容特征；若用户没有明确要求，则以本基线为准。

## 跨平台执行边界

- 平台层只负责把文字、无字画面、原图和元数据交给核心渲染器。
- 3:4 页面、白底、字体角色、边距、异形窗口、分页和响应式由渲染器决定。
- 禁止退化成通栏博客、连续大图堆叠、纯段落会议记录或常规 UI 卡片。
- 一个页面只有通过 `ache-design-system` 元信息、页面边界与四视图校验后，才能写入正式月册。
- 缺少 `ache-design-system/1.5.0`、`ache-monthly-renderer/2.3.0`、`data-theme-source` 或 `data-frame-fit` 的平台自制 HTML 不是正式月册；不得因“能打开”而放行。
- 飞书是已验收3:4页面的连续阅读镜像，不在平台内重做排版。月册只保留标题、短导语和完整成品页；页面必须全宽等比、按页码排列、无重复图注与插入正文。
