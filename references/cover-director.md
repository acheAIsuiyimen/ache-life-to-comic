# 单集封面导演

每个新章节生成一张封面。标题和封面语法随当次内容、情绪与主要物件变化。

封面画面必须独立生成并适配严格 3:4，不能从正文图、原照片、连续场景或解释图中裁出。相邻章节的两种封面语法不重复；稳定重渲染保持同一决定。

## 先建立导演卡

每次必须保存四项，不能只让模型“画得好看”：

- `coreObject`：内容里真实存在的一个核心物件、空间或概念；
- `emotionVerb`：这次记录真正发生的情绪动作；
- `smallContrast`：一个不虚构事实的微小反差；
- `grammar`：`environment-transformation` 或 `typography-in-scene`。

再结合空间、天气、未说完的张力和一句可收藏的标题完成封面 brief。画风只负责媒介一致，不能替代内容导演。

会议标题优先来自：

- 会议主题
- 最重要决定
- 未决张力
- 下一行动

没有结论时不能写成已经形成决定。

## 02 默认语法

当前启用：

1. `environment-transformation`：环境或物件发生诗意变化。
2. `typography-in-scene`：标题笔画成为道路、风线、云、窗帘或空间。

相邻两章不重复主语法。稳定重渲染不更换语法，用户明确说“换一个”时才重抽。

## 不复用

- 固定人物
- 固定云朵
- 固定风筝
- 固定窗帘
- 固定标题句式
- 样张的具体构图

固定的是画风 DNA、文字气质和版式门槛。

## P 照片封面

照片正文负责证据，封面负责语义入口。封面从原图可见物件、天气、时间感和用户文字中提炼独立视觉主意；不得把原照片套滤镜、换媒介、沿原机位重画，也不得直接把原图放进封面。

例如雨天照片可以把“窗、雨、小票、倒影”重组为一条被雨水打湿的纸带；这属于语义重组。把同一扇窗和同一把伞改画成粉蜡笔，仍属于照片转绘，必须判失败。

P 提交时同时满足：

- `cover-visual` 与正文 `body-photo` 不是同一文件；
- 封面导演卡四项齐全；
- 正文包含逐字节保留的完整原图；
- 人工确认封面不是滤镜化、转绘或复刻照片构图。

## 五路由导演重点

- S：一个视觉中心用单一写意画面；多节拍按远景、动作特写、情绪结果推进，不把一张图裁三次充数。
- P：语义封面与完整原图职责分离；1–4 张优先纵向接力、错落手帐或主格加两小格，顺序从上到下。
- K：先建立可追溯事实链，再只画一个最需要解释的过程、关系或状态变化。
- M：封面来自主题、决定、未决张力或下一行动；正文以决定、风险、待办等真实结构为主，普通会议不强行多格漫画。
- L：全文核心隐喻只进入封面；正文原文优先，少量页边轻插图不得挤压段落。

## 阻塞失败

- 把内页图、原照片或原照片转绘直接当封面；
- 没有导演卡就进入生图；
- 固定复用上一章的角色、云、风筝、构图或标题；
- 为了诗意虚构输入中不存在的事件事实；
- 素材准备时把角色、物件或动作裁成残缺画面，再依赖 CSS 隐藏问题。
- 封面实际比例不是 3:4，或通过裁正文素材伪装成 3:4。

## 文字

图片只生成无字主视觉。标题、日期与页码走确定性排版。

艺术页中不得出现系统对用户解释产品流程的话术、CTA 或“下次把内容交给我”。
