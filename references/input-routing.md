# 输入路由

## 内容单元

先把一次提交拆成内容单元：

- 原始文字
- 原始照片
- 链接与来源
- 知识事实
- 会议发言、决定、风险、未决和待办
- 用户完整长文
- 朋友圈或公开分享意图
- 用户对上一章的补充、纠错或续接

每个单元保留 `source_unit_id` 和原始值。

## 复合输入

建立关系图：

1. 同一事件、同一主题或明确依赖：同一连通分量。
2. 同一连通分量可形成复合单集。
3. 每页只能有一个主要路由；不同路由可以跨页协作。
4. 彼此独立的连通分量拆为多集，每集独立封面。
5. 朋友圈若只是发布本章，不增加章节，写入 `public_share_draft`。
6. 只有合并或拆分显著改变隐私、费用或原意且无法判断时，才问一次选择题。

## 章节边界

以下情况不新建章节：

- 补传上一章素材
- 纠正错字或事实
- 只修改排版
- 处理系统错误
- 明确说“接着上一条”

以下情况新建章节：

- 新事件
- 新主题
- 新会议
- 新学习记录
- 独立长文
- 用户明确说“新开一章”

## 路由

- `S`：日常、想法、心得、情绪、轻事件
- `P`：原始照片是主要证据
- `K`：知识学习、概念解释、读书中的事实
- `M`：会议、访谈、讨论与行动记录
- `L`：用户确认原文已经足够，只要排版与轻插图

读书笔记可以是复合路由：

- 书中内容：K
- 用户理解：K 或 S
- 个人反应：S

不要把三层混写成作者原话。

## 路由优先级

1. 用户显式要求且不伤害原文/事实
2. 证据载体
3. 内容职责
4. 篇幅与视觉预算

路由只决定主要页面语法，不决定固定页数。
